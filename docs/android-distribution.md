# Android 发布渠道与当前准备情况

核对日期：2026-11-16。本次仅查询公开规则和本地配置，没有创建商店账号、支付、生成发布私钥或提交 Android 审核。

## 渠道与费用

国内可考虑应用宝、华为应用市场、小米、OPPO、vivo、荣耀；各家分别审核，个人账号可注册不等于该类别一定能以个人主体发布。国内渠道的当前入驻费用、类目准入和材料要求，须在选定渠道后台核对，不能统一承诺“全部免费”或“个人都能上”。本次尚未登录这些 Android 商店。

Google Play 的开发者账号注册费为 **25 美元，一次性**。新个人账号公开发布前另有测试要求：2023-11-13 后创建的个人账号通常须至少 12 名测试员连续加入封闭测试 14 天，随后申请生产访问权限；付注册费本身不保证审核通过。[注册及费用](https://support.google.com/googleplay/android-developer/answer/6112435?hl=en)、[个人账号测试要求](https://support.google.com/googleplay/android-developer/answer/14151465)。

账号费用、商店推广投放、第三方代办、服务器和模型调用是不同成本。本次未采购代上架、认证或推广服务。

## 语渡当前还需要完成的准备

1. `android/app/build.gradle.kts` 中 release 仍使用 debug signingConfig。应在正式发布前配置并妥善备份正式签名，确认旧测试安装迁移方式。当前应用 ID 为 `com.wang.lingfer`。
2. 分别准备 Android 真实截图、功能说明和屏幕共享／悬浮窗用途演示。iOS 海报不能当成 Android 效果图。
3. Flutter 与 iOS 已加默认关闭的联网 AI 许可；Android 原生 `MultilingualTranslator.kt` 的直接请求路径还需接入同一许可。现阶段不能宣传所有 Android 原生请求已经完成这项门控。
4. 对选定渠道核对 APP 备案、主体及软件权属等要求，并准备公开隐私政策、联系邮箱和权限说明。华为的 Android APK 分发与原生鸿蒙包是不同目标，不把现有 Flutter APK 当作已覆盖全部鸿蒙设备。
5. 对发布包重新验证悬浮球、实时捕获、词卡、关闭／停止、本地记录、断网恢复及权限撤回；Google Play 的 AAB、目标 API 和测试轨道按提交时的现行要求核对。

建议先选一个符合个人主体与阅读工具类目的国内渠道，并准备可手动安装的内测包；Google Play 可并行安排测试员。具体开通和支付在目标渠道及要求明确后处理。
