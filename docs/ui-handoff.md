## 当前设计依据与页面结构

参考用户提供的《设计的实践》，重点落实第 9 章的任务层级（p.132）、第 11 章的正文行高和动作文案（p.166–168）、第 13 章的克制装饰（p.201–203）、第 25 章的状态矩阵（p.410–411）。书中内容仅作为设计参考。

- 导航：阅读是唯一主工作区；顶部保留文字入口“生词本”和设置按钮，分别进入独立页面并用系统返回。移除首页方形“渡”字图标、底部三图标导航和宽屏三项侧栏，不新增替代导航栏。
- 阅读：首页第一屏呈现当前学习范围与平台主要入口，不放宣传横幅。保留功能窗口现有的 Android / iOS 随屏阅读入口；截图、粘贴、相机、资料导入紧随其后。Safari 分享入口显示使用步骤，不伪装成 App 内可主动调用的系统分享功能。iOS 实时读屏的可用性及授权提示以功能窗口实现为准。
- 学习范围：一个摘要入口，展开七档可滚动列表。点选后调用原 `setLevel`，等待期间锁定重复操作；失败留在面板说明原因。
- 阅读页：普通手机用“原文 / 词卡”切换；可用宽度 ≥680dp 且文字放大不超过 1.5 倍时，原文与词卡按 6:5 并排、独立滚动。大字模式退回单栏。
- 截图阅读：识别后的正文为主，原图通过“查看截图”展开，不让截图缩略图挤走正文。
- 词卡：单词 → 基础释义 → 原句 → 语境讲解 / 熟词。原句内的目标词加粗，收藏常驻右上；移出收藏及标为熟词提供撤销。
- 生词本：保留收藏原句和基础释义，明确“初次空内容”与阅读页的“当前范围无匹配词”含义。
- 设置：阅读范围、熟词数量、AI 连接检测、离线能力、平台使用方法、隐私。连接检测结果忠实使用控制器的状态，不把服务可达误写成模型可用。

## 视觉参数

以 `lib/features/companion/lingfer_theme.dart` 为准，原生端复制数值，不另起配色。

| 角色 | 数值 | 用法 |
| --- | --- | --- |
| 页面底色 | #F6F6F3 | 工具页、词卡列表背景、原生启动背景 |
| 正文纸面 | #FFFFFF | 正文、面板、卡片 |
| 主文字 | #222828 | 正文、标题、释义 |
| 辅助文字 | #667073 | 来源、范围、说明 |
| 操作色 | #365F70 | 主按钮、选中、原句目标词 |
| 轻选中底色 | #EAF0F1 | 已选难度、信息提示 |
| 分隔线 | #E5E5EA | 1dp 边线、原句左边线 |
| 错误文字 / 底色 | #9B4525 / #FFF1E9 | 失败提示，配文字和图标 |

- 页面左右 16–26dp，宽屏 32dp；主要组距 24–30dp，组内 6–16dp。
- 首页品牌标题 32sp / 600，中文标题使用 LingferDisplay 衬线；区块 20–25sp / 600；释义 16sp、1.65 行高；辅助说明 12–13sp。正文、按钮和设置行使用系统无衬线，避免全屏仿书法。
- 英文正文 20sp、1.85 行高，最大排版宽度 640dp。优先 Georgia / 系统衬线；UI 使用系统无衬线。词头 27sp，不强制截断长单词。
- 纸面卡片圆角 24dp，主按钮为胶囊，底部面板上角 30dp。正文不加玻璃滤镜。范围、语言、关闭和设置等控件及浮层可用有边界的玻璃，参数沿用 `lingfer_glass.dart`：模糊 22、细白边、轻投影；不可把整个阅读页变成透明层。
- 高对比、减少动效或辅助导航开启时，玻璃退为实色。文字与边界仍应可辨；操作色上白字约 6.94:1、辅助文字在页面底色上约 4.7:1。
- 启动使用与首页一致的浅色原生背景，不再引用旧启动位图，不加品牌口号或人为延时。Android 12 的启动图标使用透明资源，避免系统回退到旧启动图案。
- 操作热区至少 48×48dp；不靠颜色独自区分收藏、范围或失败。系统字号正常响应，不缩字强塞一行。
- 使用系统返回、文本选择、相册和权限交互；动效跟随系统组件，不新增装饰动画。

本轮同步重点：面板底色为稳定纸面白，标题改用衬线、工具文字保持系统字体；范围、关闭等操作可使用轻玻璃。玻璃参数不可降低正文对比，不在整块 OCR 原文后加模糊。原生端采用与平台兼容的有边界材质，能力不足时使用浅色实底，不增加新的第三方渲染依赖。

1. 悬浮按钮使用居中的线性阅读图标、48dp 点击热区；待机纸面/墨蓝，会话中保留停止入口。识别进行时显示进度并禁用重复捕获，不用循环脉冲吸引注意。
2. 面板顶部为“本页词卡”与关闭操作；下一行为当前范围、匹配数量、识别状态。范围点开七档列表，不在窄面板平铺七个胶囊。
3. 可用宽度不超过屏宽减 24dp，普通手机建议 360dp；大屏上限 440dp。最大高度不超过可用屏高的 72%，内容独立滚动，顶部标题和底部“重新识别 / 停止阅读”可达。
4. 词卡顺序和样式复用上述规则；收藏立即变为实心图标、无跳转。标熟词后收起该项，并通过现有操作提供撤销；不要为此改数据格式。
5. AI 讲解在该卡片或面板内展开，保留原句和离线释义；加载显示“正在结合原文讲解…”，失败显示原有业务错误和“重新请求讲解”。不清空已识别内容。
6. 旋转、折叠、切换分屏后重新约束面板位置，避开手势区域、折痕和系统栏；悬浮按钮可拖动到安全边缘。保持现有防止识别自身浮层的逻辑。
7. 关闭词卡面板与停止捕获会话必须区分：关闭只关闭面板，“停止阅读”才结束会话。权限仍交由系统页面处理。
