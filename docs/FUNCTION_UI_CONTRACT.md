# 多语言、原词定位与自动更新：功能接口

2026-11-08，本功能窗口已接入控制器、识词/翻译服务、Android 实时读屏与 iOS 原图 OCR。保留 UI 窗口新建的 shell / components / reader / sheets 和主题，不恢复旧界面。

用户随后明确要求原词玻璃框、原图定位与实时更新，因此这些位置采用最新需求，覆盖早先 `ui-handoff.md` 中“不使用玻璃”和“截图默认收起”的建议。普通首页、导航、设置继续保留 UI 窗口的纸面布局。实际运行验证见 `LIVE_READING_2_1.md`。

新增领域接口：`ReadingPreferences` 提供源语言、目标语言、自动更新和非英语通用难度；`CompanionController.preferences` 与 `setReadingPreferences()` 持久化并同步原生。原有 controller、bridge、书架和保存格式保持兼容。英语任一方向仍验证本地考试词表；非英语通用难度为学习参考，不冒充考试词表。

新增 `OcrDocument` 保留原图尺寸、文本片段、每个词真实识别框与 UTF-16 范围；`VocabularyHit` 增加原文位置、语言与短译义。截图阅读将显示原图和邻近玻璃标注，空位不足时只保留可点击原词标记，不盖住别的文字。

Android 自动读取仅在用户开启屏幕捕获会话后运行；滚动时隐藏旧标注，稳定后重识别。指纹忽略语渡自己的浮层，云端翻译只处理变动后的文字并缓存，暂停/停止释放或停止扫描。多语言自动翻译需要新的会话说明，替换“仅点 AI 才发送文字”的旧说明。

新展示组件由功能窗口提供独立接口，UI 窗口可在核心实现稳定后调整外观。两端语言选项应连接同一个 controller。iOS 分享/截图可定位显示；跨其他 App 常驻扫描仍是 Android 能力，不宣称 iOS 提供同样权限。
