# 语渡 Lingfer

语渡是一款用 Flutter 开发的多语言阅读应用，支持本地书籍和资料、原句词卡、生词复习，以及 Android 和 iOS 各自的随屏阅读入口。

当前排查基线为 TestFlight **2.1.1（15）**。11 月 19 日用户再次报告，iPhone 开始随屏阅读后画中画浮窗没有出现。复现步骤、诊断入口和验收条件见 [iOS 首次浮窗交接](docs/ios-pip-handoff.md)。

## 当前功能

- Android：用户授权的实时屏幕读取、原词旁玻璃译义框、点击详解、暂停／继续、长按停止。
- iOS：支持系统画中画、灵动岛及原生系统分享扩展。分享扩展可接收 Safari 选中文字或可见正文，以及其他 App 分享的文字和截图。
- 两端：10 种语言选项、源语言自动识别、英语相关方向七档考试范围、非英语基础／进阶／高阶参考分级。英语→中文基础释义使用 11,441 条离线词表，其他方向联网翻译。
- 新版阅读／生词本／设置采用温白纸面和墨蓝操作色；原词标注和详解使用玻璃材质。
- 支持导入本地 `TXT / EPUB / PDF / DOCX` 文件并加入书架。
- 支持从 `文件 / 照片 / 相机` 三个入口添加内容。
- 支持图片 OCR 与拍照扫描，识别后的文本可直接长按学习。
- 支持 `TXT / EPUB / DOCX` 文本阅读，以及 `PDF` 原样渲染阅读。
- 支持长按选词、整段翻译、核心生词提取，并通过 Apple Glass 风格浮层展示。
- 支持多档词汇难度切换，例如四级、六级、考研、雅思、托福等。
- 支持中英学习模式切换、主题切换、字号调节、书签与高亮标记。
- 支持阅读进度记忆、本地缓存，以及删除书籍时同步清理缓存。
- 本地资料入口保留在新版主页；原有读书器继续兼容旧数据。

## 技术栈

- Flutter 3 / Dart 3
- `epubx`：EPUB 解析
- `syncfusion_flutter_pdfviewer`：PDF 阅读
- `docx_to_text`：DOCX 文本提取
- 原生 ML Kit：Android 图片与随屏 OCR
- Apple Vision：iOS OCR
- `shared_preferences`：进度、书签、缓存状态持久化
- `path_provider`：导入文件与缓存目录管理
- `http`：AI 代理请求

## 运行前准备

1. 安装 Flutter SDK，并确保 `flutter doctor` 基本通过。
2. 如需启用 AI 功能，请准备代理服务地址与应用密钥。
3. iOS/macOS 首次运行前，建议执行一次 CocoaPods 安装。

## 本地运行

### 安装依赖

```bash
flutter pub get
```

### 安装 iOS Pods

```bash
cd ios
pod install
cd ..
```

### 运行 iOS 模拟器

```bash
open -a Simulator
flutter run -d <模拟器设备ID> --dart-define-from-file=config/runtime.json
```

### 运行 macOS 桌面版

```bash
flutter run -d macos \
  --dart-define=DEEPSEEK_PROXY_URL=https://你的代理地址 \
  --dart-define=APP_SECRET=你的应用暗号
```

## 使用方法

### 添加内容

- Android 主页选择语言和学习范围，点“开启随屏阅读”，授权“共享整个屏幕”。切换页面后自动标注；点“渡”暂停／继续，长按停止。关闭自动更新时仍可点“渡”手动识别。
- iOS 可从系统分享菜单进入语渡，或在主页点“选择截图”；点击原图上的译义或下划线查看详解。
- 主页“换一种方式读”提供粘贴文字、拍照识别、导入资料三个入口。
- 导入的 TXT / EPUB / PDF / DOCX 以及旧版资料，继续保存在主页“接着读”的本地书架中。

### 阅读与学习

- 点击书架中的书籍卡片进入阅读页。
- 新版词卡提供离线释义、原句、收藏、熟词排除和按需语境讲解；收藏集中在“生词”页。
- 长按正文或 PDF 文本，可触发翻译 / 生词提取面板。
- 阅读页可切换词汇难度、语言模式、主题、字号与排版方式。
- 可添加书签与高亮，方便后续复习与回看。

### 删除书籍

- 在书架中长按书籍卡片。
- 点击“删除本书”后，会同步清理书架记录、阅读进度与翻译缓存。

## AI 配置说明

模型 API key 只保存在服务器。客户端通过未纳入版本管理的 `config/runtime.json` 注入以下连接参数，格式参考 `config/runtime.example.json`：

- `DEEPSEEK_PROXY_URL`
- `APP_SECRET`

如果未传入，识别、分级筛词、基础释义和收藏仍可使用；AI 讲解会提示尚未连接。客户端访问令牌随应用分发，不等同于用户账号鉴权；公开运营前应结合用户体系与限流控制模型用量。
